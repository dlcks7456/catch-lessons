CatchLessons

Captions and translations for system audio.

Prerequisites: Install and sign in to Codex CLI or Claude Code before use. The app checks both agents on startup.

Codex: developers.openai.com/codex/cli
Claude: code.claude.com/docs/en/setup

The installer cannot reliably inspect user-specific CLI paths. Check the selected agent in the app after installation.

Speech recognition: Local Whisper is selected by default. If you deselect it, choose OpenAI API and provide an API key. Audio will be sent to OpenAI.

macOS 14 or later and screen/audio recording permission are required.
